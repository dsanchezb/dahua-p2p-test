Dahua P2P Live Viewer

View a Dahua / derived (NVR or camera) live feed in the browser using only its device serial (P2P ID / SN) and username / password — no port forwarding required. Built on the dh-p2p P2P/PTCP tunnel implementation.

Connect

Credentials are only used to establish the P2P tunnel and RTSP session for this browser tab; they are held in server memory for the lifetime of the session and are not persisted to disk.
